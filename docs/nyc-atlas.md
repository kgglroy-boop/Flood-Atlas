# 纽约牙买加湾案例与案例库

首页默认打开 2021 年 9 月 1 日 Ida 暴雨的牙买加湾北岸研究区。航拍、建筑、道路与水系来自公开地理资料。三种峰值水深来自 Kasaei 和 Orton 的预计算模型输出，分别为 Ida 复盘、雨带东移、雨带北移。每格峰值可能在不同时间发生。原始课程六时步从「教学档案」进入，使用原有 v1 服务。

## 启动与打开

在 Windows 项目根目录，用 PowerShell 7 运行以下命令。首次运行先复制 .env.example 为 .env，设置两个本机密码。

~~~powershell
docker compose up -d --build --wait
pwsh -NoProfile -File scripts/publish-nyc-case.ps1
~~~

打开 http://localhost:5173/。程序使用本机的地图和数据。数据来源和裁剪方法详见 data/processed/cases/nyc-ida/source.json。

## 导入自己的模拟

1. 运行 pwsh -NoProfile -File scripts/enable-case-import.ps1 -Copy，将本机导入密钥放到剪贴板。
2. 在首页选择「导入案例」，输入密钥，填写案例标识和名称。
3. 按顺序绑定各步的单波段水深 GeoTIFF。标明原始单位、阈值、峰值或时间步。可以指定合适的米制 EPSG 坐标系，也可以让程序按研究区选择本地 UTM。
4. 按需附加 GeoJSON 或 GeoPackage 的建筑、道路和水系，GeoTIFF 影像及 AOI。使用同一标识更新时，可复用所选旧版的配套图层。预检要求复用图层所依赖的新旧范围重叠至少 90%。
5. 检查覆盖、干湿像元数量与预览统计，确认后发布。新旧版本可在案例下拉框选择。
6. 在案例「来源」面板内导出案例。ZIP 可重新导入，或者用离线脚本直接查看。

GeoTIFF 需要已定义坐标系，有效分辨率和范围，包含有效深度。跨地区案例用新标识及对应的配套图层。无建筑或道路资料时，相应统计显示不可用。阈值采用严格大于，NoData 维持无覆盖。

## 离线阅览

交付包带静态页面和默认案例快照。安装 Python 3.11 或更新版本，在源码根目录执行：

~~~powershell
pwsh -NoProfile -File scripts/open-case-offline.ps1
~~~

访问 http://127.0.0.1:5174/。使用自己的案例 ZIP 时，在命令末尾附上 -Archive 和该文件路径。离线阅览使用快照自带的水深、影像、几何和统计。发布与重新计算在在线环境完成。

## 数据和验收

- NYC 统计使用 EPSG:32618，水深归一为米，水深网格为 35 m。面积是有效湿像元面积；建筑要求正面积相交；道路交集合并后测量。常年水面排除，湿地和潮滩参与分析。
- 2026-11-12 实测版本 bf37267f4becb2844107。见 docs/evidence/nyc-atlas-20261112。QGIS 交叉核验与本机性能测试分别记录，人工签字保留给项目负责人。
- 实景模型及影像由公开来源提供。统计用于案例比较与课程复盘。

# 项目范围与完成标准

本项目用于GIS软件工程课程，展示预先准备的内涝水深如何经过GIS服务、空间数据库、API和浏览器地图形成可解释、可重建的全链路系统。“AI辅助”指AI协作开发与人工审查。

最终范围：1—3 km²演示区，两个情景、三个时间步、六张水深GeoTIFF；一页地图；淹没面积、受影响建筑数量、受淹道路交集长度；建筑Popup；CRS、安全、GiST、GWC、低压并发及矢量瓦片检查。先使用教学合成数据，页面和报告明确其性质。

阶段1只交付工程目录、规则、四服务Compose、PostGIS初始化、数据库就绪接口、空MapLibre地图、连接状态、自动检查和操作说明。空间表、演示区、ANALYSIS_CRS、像元大小、NoData与数据生成规则在阶段2确定。

阶段1已获负责人确认。阶段2按已审阅设计实施：EPSG:32650的虚构2km×1km街区，200栋建筑、32条道路，六张5米Float32水深及淹没范围，独立flood schema事务导入和QGIS核查。所有数据明确标注synthetic_demo；当前不发布地图服务或新增业务HTTP接口。

淹没提取条件为 depth > 0.10 m。地图链为 Browser → GeoServer/GWC，分析链为 Browser → FastAPI → PostGIS。长度和面积使用合适的本地米制投影。

不做在线模拟、模型训练、可微分建模、避险路线、实时预警、登录、三维、LLM Agent和额外大屏。系统不代表经过验证的洪涝预测或风险预警。

教师原始评分细则、课程截止日期和允许的提交方式尚未提供。MVT在阶段4结束前核实，若仍未明确，阶段7保守完成一个建筑MVT接口示范。

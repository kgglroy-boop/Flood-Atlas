# Flood Atlas 前端代码审查与改版

审查对象为纽约案例地图、矢量瓦片页及案例导入流程。改版采用现有 Vue 与 MapLibre；原教学档案仍可从案例库打开。

| 等级 | 旧版问题 | 本轮修改 |
| --- | --- | --- |
| P1 | WMTS 报告瓦片元数据时便显示就绪，部分 404 不会触发错误事件。 | 等待成功解码的瓦片；在研究区内等待超时后尝试快照，并允许重试。主图与对照图分别处理。 |
| P1 | 把案例统计依附于水深图层的可见性和就绪状态，隐藏水深后切换场景可能使统计空白。 | 用当前情景的统计数据直接渲染，瓦片错误独立提示。时间播放在隐藏水深时仍能推进。 |
| P1 | 导入任务查询失去授权后，页面隐藏原密钥输入框，只能用相同密钥反复重试。 | 保留任务并允许重新填写密钥，分别恢复进度查询和发布。 |
| P2 | 时间步重复出现在场景按钮和滑杆，导出密钥只能在导入向导填写。 | 以情景分组，时刻只出现在时间轴；来源面板直接接收导出密钥。 |
| P2 | 卷帘的透明输入横跨地图中线并抢占点击。 | 指针由可见手柄捕获，键盘继续使用原生范围控件。 |
| P2 | 建筑点查无明确加载状态，切换情景丢失所选位置。 | 显示查询进度和无覆盖状态，点查面板打开时用新情景刷新同一点。 |
| P2 | 矢量瓦片页缺少水体，点击未设置选中态；返回时丢失案例版本，前进后退缓存可恢复空地图。 | 增加水体与高亮，带案例和版本返回地图，保留浏览器缓存中的地图实例。 |
| P2 | 同一编号可合法出现在不同类型的地物中，按原编号高亮会选中多个地物。 | 矢量瓦片高亮同时按地物类型和编号筛选。 |
| P2 | 无法打开的固定版本可能退回默认并改写地址，导入表单的校验也比后端更窄。 | 明确报告固定版本不可用，提供默认案例和教学档案入口。表单接受后端支持的标识与小数分钟。 |

## 视觉与操作

- 全视口使用实际航拍与水深。标题、情景、图例与地图工具在影像上保持独立层级。
- 案例库管理版本、导入、教学档案及矢量瓦片。地图操作常驻缩放与复位，底图、水深显隐和地图中心点查收进图层面板。
- 统计按需打开，建筑搜索独立，点查详情自动呈现。导入使用同一深色界面和分层表单。
- 小屏面板从底部打开。键盘可进入地图、调整卷帘、退出面板。响应浏览器的减少动效、高对比与减少透明度设置。

视觉依据见 [Portal 官方网站](https://portal.app/)、[Portal 的 Liquid Glass 设计记录](https://portal.app/campfire/liquid-glass-portal-digital-age-of-biophilic-design) 与 [Apple Materials](https://developer.apple.com/design/human-interface-guidelines/materials)。

## 验证

- Node 24 下 50 项前端测试通过。Docker 前端类型检查、生产构建和服务健康检查通过。
- 运行页面验证纽约情景统计、卷帘的实际拖动与键盘操作、建筑搜索、地图中心点查、时间轴播放、MVT 同版本返回和离线快照。隐藏水深后切换纽约情景仍显示 782,775 m²。
- 实测桌面 1440×900 和手机 390×844。手机对照开启时，统计面板底边为 618 px，情景区顶部约为 633 px，视口宽与页面宽均为 390 px。
- 导入恢复用浏览器模拟服务验证，包括作业轮询与发布返回 401 后更换密钥重试；本轮浏览器打开实际导入界面，未新发布数据。
